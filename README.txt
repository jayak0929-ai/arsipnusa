ARSIPNUSA — WEBSITE RESPONSIVE PROYEK RPL

Website ini sudah disiapkan agar tampil menyesuaikan:
- Laptop / komputer
- Tablet
- HP Android dan iPhone

CARA MEMBUKA DI LAPTOP
1. Ekstrak ZIP.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder arsip-digital-rpl.
4. Buka index.html.
5. Klik kanan > Open with Live Server (jika ekstensi Live Server terpasang).
   Atau buka index.html langsung di browser.

CARA MEMBUKA DI HP
Agar website bisa dibuka lewat HP dengan alamat/link seperti website sungguhan,
folder website perlu diunggah ke layanan hosting statis (misalnya GitHub Pages).
Setelah dipublikasikan, buka link website tersebut dari browser HP.
Jangan hanya mengirim file index.html saja; unggah seluruh folder agar CSS dan JavaScript ikut terbaca.

FITUR
- Dashboard arsip digital.
- Tambah, cari, dan hapus arsip tokoh.
- Data arsip tersimpan di localStorage browser.
- Enkripsi dan dekripsi Caesar Cipher.
- Tampilan responsif untuk layar kecil dan besar.

CATATAN
Ini masih prototipe front-end. Data tersimpan di browser/perangkat masing-masing,
belum tersambung ke database MySQL atau login online. Caesar Cipher hanya untuk
demonstrasi pembelajaran, bukan metode keamanan yang kuat.
